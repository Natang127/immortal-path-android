# Jarvis Remote (Android)

Phone app for the Jarvis PC assistant: live video of the PC, tap-to-click control, chat and voice.
Built automatically by GitHub Actions — download `jarvis-remote.apk` from the **jarvis-latest** release.

Setup: text `app` to your Jarvis Telegram bot, long-press the link → Copy, open the app. Done once;
after that the app finds the PC's new address by itself whenever Jarvis restarts.
